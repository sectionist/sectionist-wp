# 7. License: GPL-3.0-or-later

Status: accepted

## Context

WordPress is GPL-2.0-or-later. Plugins and themes distributed for WordPress must be GPL-compatible.

## Decision

All packages are licensed GPL-3.0-or-later. There are no premium dependencies.

## Consequences

- Compatible with WordPress, free to use, modify and redistribute.
- Derivative works must stay GPL-compatible.
- Dependencies must have GPL-3.0-compatible licenses.

## Rejected alternatives

- **GPL-2.0-or-later:** also compatible, but gives less patent protection.
- **MIT:** compatible, but permits proprietary derivatives, which conflicts with the no-lock-in principle.
